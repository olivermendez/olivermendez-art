# Logos de tecnologías y herramientas

Los logos se sirven desde `public/logos/tools/`, sin dependencias de un CDN en tiempo de ejecución.
Las marcas pertenecen a sus respectivos titulares.

- La mayoría de los SVG proviene de [Simple Icons](https://github.com/simple-icons/simple-icons),
  commit `1bb2f6e6ea50f920de8d2f3d273ae48564a5eaee`, carpeta `icons/`.
  Se define el relleno para que cada icono se lea sobre su fondo.
- VS Code: `vscode.svg` del [paquete oficial de iconos](https://code.visualstudio.com/assets/branding/visual-studio-code-icons.zip),
  enlazado desde las [guías de marca de VS Code](https://code.visualstudio.com/brand).
- Groq: [favicon SVG del sitio oficial](https://groq.com/favicon.svg).
- Codex: [Lobe Icons](https://github.com/lobehub/lobe-icons), commit
  `ea434b96e75813517b377825e01c0df61dee8836`, `packages/static-svg/icons/codex.svg`.
- SwiftUI comparte el símbolo de Swift; no se presenta como un icono independiente.
